# 第三课 条件判断
## REPL 探布尔
- 5>3 True
- 5==5 True
- 5=="5" False
- type(5>3) class 'bool'
- if x=5: 错误语法 x=5是赋值
## 缩进规则
示例：
```
score = 85
if score >= 60:
    print("及格了")
```
- print 前面有 4 个空格。这不是排版好看，这是语法——缩进表示"这些行属于这个 if"。其他语言用花括号 {}，Python 用缩进，逼你写出整齐的代码。
- 规矩：if 行末尾加冒号 :，属于它的代码统一缩进 4 格（VS Code 里按一下 Tab 自动搞定）。缩进错了会撞见 IndentationError
## 比较运算符
- > < >= <= !=
## = vs ==
- =是赋值 ==是等于
## elif 执行顺序
- 先执行if，任何从上到下依次执行elif，最后到else
- 如果存在两个以上的if，都会执行，不会像elif一样的单链路运行，他们是并列的。
## 逻辑运算符
- and（两个都真才真）、or（一个真就真）、not（取反）
