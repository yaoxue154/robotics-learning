# 第一课认识python
## 解释型
- python的代码由"解释器"（interpreter）逐行翻译执行，写完就能跑。阶段 3 要学的 C 是编译型（先整体编译成机器码再运行）
## 两种运行方式
- 第一种：对话模式（REPL）。 终端敲 python，看到 >>> 就进去了——词源 Read-Eval-Print Loop（读一行→算一行→打印→循环）。一行一行聊，适合试错。退出敲 exit()。
- 第二种：脚本模式（正餐）。 代码写进 .py 文件，python 文件名.py 运行。脚本（script）就是"剧本"——计算机照着演。
## 变量
- variable（可变的）。变量就是一个贴了名字标签的盒子，盒子里的东西有类型（type）
# 赋值
- `=` 叫赋值（assignment）——把右边的值，放进左边这个名字里。注意：= 不是数学里的"等于"，它是动作，方向从右到左。
## 词源
- str 字符串	string，一串字符	"yaoxue"（引号包住）
- int 整数	integer	18
- float 浮点数	带小数点的数	95.5
- 查看一个变量的类型：问 type()：print(type(name))    # 输出 <class 'str'>
## 脚本
- 写好的代码脚本，就像写好的剧本，通过命令，可以让python程序按照脚本运行
- 脚本里放的就是有顺序的指令
- 脚本的目的是自动化，REPL就像鼠标键盘在资源管理器上的操作，是即兴的
# 示例
- 脚本
```
name="yaoxue" 

age=18

score=95.5

print(type(name))

print(type(age))

print(type(score))  

print(name,age,score)
```
- 运行效果
```
<class 'str'>

<class 'int'>

<class 'float'>

yaoxue 18 95.5
```
# 第二课运算与输入
## 运算符
|运算符|名字|例子|结果|
|:----|-----|----|----:|
|//|整除|17 // 5|3（只留整数部分）|
|%|取余（模）|17 % 5|2（除完剩下的）|
|**|幂|	2 ** 10|1024|
## input的陷阱
- input 拿到的东西永远是字符串，打入18拿到"18"如：fn=input("第一个数字：")写入18后得到"18" 无法参与运算
- 解决办法是转换，见下
## 三种转换
- int("18") → 18（字符串转整数）
- float("95.5") → 95.5（转浮点）
- str(18) → "18"（转字符串）
- 示例 小数转整数
```
int（float（"19.9"））得到19，小数部分直接砍掉，不是四舍五入
```
## 陷阱
- 检查后认为语法没有错误还是报错，记得看看是不是用了中文的符号，python只认英文SyntaxError: invalid syntax
- 字符串前面加 f，大括号 {} 里直接放变量/表达式——f = formatted（格式化的）如:
```
age = 18
print(f"今年{age}岁")
```
也可以
```
age=18
print("今年",age,"岁")
```
- 引用变量时不要瞎带括号 float()带括号是因为转换语法需要
