# 第 10 课《从列表到数组——NumPy 的第一行》
1. 列表和数组都是按照位置取值，字典按照键来取
2. 数组要求统一类型，列表随便混装
3. 数组的运算全部一起，全员生效（向量化）列表则需要循环
4. 向量化就是把"一排数"当一个整体直接运算
# 第 11 课《二维数组——矩阵登场》
1. .shape是形状，现实数组的格式，比如3x3。
2. :在索引处的意思是全部
3. 示例：
```
import numpy as np
grades=np.array([[89,22,67],
                 [97,79,90],
                 [69,87,70],
                 [87,98,58],
                 [70,80,40],
                 [80,90,60]])
print(grades.shape)
print(grades[5,1])
print(grades[:,0])
print(grades.mean(axis=0))
print(grades.mean(axis=1))
```
- axis=1是取每一行的意思（有点循环的感觉，“每一行”）
- axis=0是取每一列的意思（axis的原意是轴）
# 矩阵向量(审讯术)
- x轴起点默认向右，y轴起点默认向上
- R=[[0,-1]（向量x）,
     [1,0 ]（向量y）]
     第一列获得向量（0，1），向上，x轴逆时针旋转90度，第二列获得向量（-1，0），向左，y轴逆时针旋转90度
     。第一列管x轴终点，第二列管y轴终点，这是规定，
- @ 运算规则，如例子：

P=【1，0】（是一个向量，命名为向量p）

R@P 的解法为，R@P=(向量x*向量p,向量y*向量p),(*为点乘)
# 术语
|一排数（点/箭头）[1, 0]|向量|vector
|----|----|----|
|一张数字表（搬迁公告|矩阵|matrix
R @ p 这个动作|矩阵乘向量|matrix-vector product
旋转/镜像这种"搬家操作"|线性变换|linear transformation
这整门学问|线性代数|linear algebra
