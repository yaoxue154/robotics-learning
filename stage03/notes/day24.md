# 第 18 课《指针进阶——摸整排房子，让别人替你改房子》
## 数组：一排连排的房子
- 实例
```
#include <stdio.h>

int main(void)
{
    int scores[5] = { 85, 90, 78, 92, 88 };   /* 盖一排 5 间连排 int 房 */

    printf("%d\n", scores[0]);       /* 老熟人：下标取货 */
    printf("%d\n", *scores);         /* 新面孔：数组名本身就是第一张门牌号 */
    printf("%d\n", *(scores + 1));   /* 门牌号 +1 = 隔壁那家 → 90 */

    printf("%p\n", scores);          /* 排首地址 */
    printf("%p\n", scores + 1);      /* 看清楚了：地址加了 4，不是加 1 */
    return 0;
}
```
1. 数组名 ≈ 排首房子的门牌号——scores 和 &scores[0] 是同一个东西（比较反常识）
2. 指针加法自动按户型迈步：scores + 1 不是地址数字 +1，而是跳过一整间 int（4 字节），正好落在隔壁家门口。这就是为什么指针必须带类型——不带 int，编译器不知道一步迈多远*(scores)是第一个房子，*(scores+1)是第二个房子
## 函数与指针：复印件 vs 钥匙
int age=99;
age这个房子里放着99，但是age不是99，age就是这个房子，不是99这个东西。用函数处理age比如：birthday（age）是可以处理的，但是处理的是age这个房子,用*age指针（也是所谓的“钥匙”）直接指向门牌号，处理的时候就直接按照地址找房子门牌取99，对99作处理。
