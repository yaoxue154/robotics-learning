# 第 22 课《预处理与多文件——C 理论的收官之战》
## 预处理
- #后的命令就是预处理，ggc编译时先预处理后编译
- include的意思是复制，define是定义，可以替换变量值，例如"#definde max 78"效果是程序里的引用max的地方，max都变成78（注意：使用int char等定义变量的值的，define对他们不起效，会报错）
- define是替换值，所以不会产生更多的内存占用
# <> ""的区别
- <>尖括号：去系统目录找（标准库）
- ""双引号：先在你自己项目里找（自己写的）
# .h .c的分工
- .h公告牌，在里面写完整的函数title如"int add (int a,int b);"此时.c文件中写好完整的函数
"int add (int a,int b)
{
    return a+b;
}
- .c施工队，里面写完整的函数
- 不用写.h文件也可以直接引用.c的函数但是要写一遍"int add (int a,int b);,所以.h文件存在的目的是统一管理,否则重复手写，或者找不到对应的写到哪一行了，会不好处理。
- 需要在预处理时用#include"math.h",编译时要编译gcc main.c math.c -o app.exe
