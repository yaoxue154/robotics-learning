## 新的变量认识方式
写法	意思
int age = 18;	盖一间 int 户型的房子，门牌叫 age，先放 18。Python 里 age = 18 是贴纸，这里是盖房
%d	占位符：告诉 printf"这里按十进制整数解读"（d = decimal）
&age	取地址：这间房子的门牌号（& = address，地址）
%p	占位符：按地址格式打印（p = pointer，指针）
- 注意：还有%f（float） %i（int）这些，%加变量类型，是为了说明。
# ALSR
- &age 每次运行打印的地址都不一样，这是操作系统故意的，机制叫 ASLR（地址空间布局随机化）：每次启动程序，操作系统把它随机放到内存的不同位置。

## 指针
- int age=18 从此之后，age这个户型里只能放数字
- int *p=&age 标记，p这张纸条上写着age的地址
- *p取出age里装的东西“18”（int时的*和取出时的*不是一哥东西）
- *p=其他可以上门改货，直接age=其他，也可以改货
- *p上门取货
