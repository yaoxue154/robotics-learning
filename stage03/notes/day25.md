# 第 19 课《位运算——寄存器的语言》
## 基础概念（0和1就是false和true）
- 进制复习（自主进行）
- 六大运算符（计算的核心原理）：
&--与，and，两个都是true的时候取true
|--或，存在true就是true
^--异或，不相同时取true（一个true一个false，无顺序）
~--翻转，1变0，0变1
## <<
- 示例，(1<<5)，如果1用八位二进制来表示，是0000 00001，(1<<5)就是0001 0000，第五位是1的掩码（mask）
## 实际使用
- 假设RRG是一个八位寄存器，假设它现在的状态是0000 0000
(int REG=0；) 
- 用1<<5可以获得掩码，这样用REG|(1<<5)就得到0001 0000
- 其他的可以按照原理一个一个拆解，以下引出四个便捷记忆的使用效果：见四大招式
## 四大招式
- REG |=  (1 << 3);    /* 开灯：只把第 3 位变 1，其他位不动 */
- REG &= ~(1 << 3);    /* 关灯：只把第 3 位变 0，其他位不动 */
- REG ^=  (1 << 3);    /* 翻转：第 3 位 1 变 0、0 变 1（呼吸灯的灵魂） */
- REG &   (1 << 3);    /* 读灯：结果非 0 就是亮着 */
格式是a 符号= b；其实和a+=1是一个道理，本质是a=a 符号 b；
- 另外一种记忆方法：
遇到的位都是掩码的位
