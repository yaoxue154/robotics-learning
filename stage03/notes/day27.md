# 第 21 课《字符串——C 里连一句话都要亲手伺候》
## char是什么？
- 一个字节（二进制四位）的户型，可以装0到255的数字以及字母
- 打印方式：两种--%c（按字符）或 %d（按数字），单引号''的每一个字母对应一个数字，使用%d，也就是说可以数字加字母运算
- 示例
```
char c = 'A';
printf("%c\n", c);        /* A —— 按字符解读 65 */
printf("%d\n", c);        /* 65 —— 按数字解读，同一个东西！ */
printf("%c\n", c + 1);    /* B —— 65+1=66，就是 B */
``` 
## char和int的区别
- int age = 18; 的全部含义就是：盖一间 4 字节的整数房，门牌 age，放 18。没有什么魔法——4 字节 = 32 位 = 能装 ±21 亿范围的整数。它比 char 唯一的区别就是房子大：
- 为什么需要两种户型？省地。循环计数 0~100 用 char 就够，装成绩、装年份用 int。嵌入式里内存金贵，STM32 上每一字节都要算计——到时候写 char 还是 int 是要过脑子的。

## 单双引号的区别
- 'A'      /* 单引号：一个字符，1 字节，住 char */
- "A"      /* 双引号：字符串，2 字节（'A' + '\0'），住 char 数组 */
## 陷阱
- char a[20] = "hello";
- char b[20] = "hello";
- if (a == b)    /* ❌ 比的不是内容！ */
- a 和 b 是两排连排房的排首门牌号——== 比的是门牌号，不是里面的字。两排房地址永远不同，所以永远"不相等"。
