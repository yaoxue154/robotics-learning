# 第 16 课《C 语言登场——从解释器到编译器》
## python与c语言的区别与共同点
- 共同点：都是编程语言
- 不同点：python具有成套的整合资源，c则遍地开花，需要一步一步安装准备
- python采用的编译器使用一行一行编译成机器码，然后机器处理的方法，属于边读边写，而c则是先写文件，gcc一次性直接把文件编译成机器码，随后运行时直接处理机器码。
- 正因此，c比python快得多得多
## 注意点
- c语言需要；来表示一句结束，对比python，在pyton里换行就是句号
- 需要#include int main（）
- c被提前编译成了机器码，二机器码为了内存对齐、为了 CPU 缓存命中、为了优化。我们写代码的顺序，基本不被保留。所以使用main作为路标。也是不同于python的，python因为是一行一行编译的，所以有顺序，c就需要main，正因如此python没有，也不需要main这个路标。
- main 主线，告知起点。
## gcc自助安装
- 下载MSYS2，运行pacman -S mingw-w64-ucrt-x86_64-gcc
1. 下载 MSYS2 安装器

浏览器打开 repo.msys2.org/distrib/x86_64/，下最新的 msys2-x86_64-日期.exe
2. 双击安装，路径默认 C:\msys64 一路下一步

3. 装 gcc：安装完会弹出 MSYS2 终端（黑窗口），输入：

pacman -S mingw-w64-ucrt-x86_64-gcc
回车，问就按 Y（pacman 就相当于 MSYS2 的 pip）

4. 加 PATH：Windows 搜索"编辑账户的环境变量" → 用户变量 Path → 新建一行：

C:\msys64\ucrt64\bin
5. 开新终端验证：

gcc --version
- 注意：用户名含中文/全角字符 → gcc 罢工 → 把用户级 TMP/TEMP 环境变量改成 C:\msys64\tmp 否则gcc罢工。
# path
- 运行程序的指引，就是一个文件路径，快速处理。
- 需要gcc的时候就跑到变量的路径去找gcc，找不到就报错。
- 路径下一般不只是一个程序而是运行程序实现功能的一整个工具链，需要按链调用，所以还不能乱设置，一般就要按照主要程序的路径设置。
